# Упражнения по функционално програмиране (ФП)

Това хранилище съдържа материали от упражненията по функционално
програмиране във ФМИ, Софийски университет, за специалност
**Компютърни науки (КН), 2. курс, поток 2**.

Материалите са **допълнение към упражненията**. На упражненията
решаваме задачи, коментираме материалите, гледаме какво прави
интерпретаторът и говорим за начина на мислене, не само за синтаксис.

## Структура на хранилището

```text
fpUpr/
├── README.md              ← вие сте тук
├── .gitignore
└── week-01/ … week-NN/    ← по една папка на седмица
    ├── README.md          ← теория и бележки за упражнението
    ├── tasks.md           ← задачи за решаване на упражнението
    ├── homework.md        ← домашна работа (когато я има)
    └── solutions.rkt      ← решения (Racket). по-късно .hs
```

Хронологията е по седмици. Всяка следваща седмица стъпва върху
предишните. Следвайте ги по ред.

## Как да навигирате

1. Отворете папката на седмицата (`week-01`, `week-02`, …).
2. Прочетете `README.md` в съответната седмица, препоръчително преди
   упражнението, но може и по всяко време след него.
3. `tasks.md` са задачите, които решаваме заедно на упражнението.
4. `homework.md` (когато го има) е за самостоятелна работа след упражнението.
5. `solutions.rkt` / `.hs` са решенията към задачите от седмицата.
