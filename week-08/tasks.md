# Седмица 8 - задачи

Задача 1. Да се дефинира функция incrementAllBy :: [Int] -> Int -> [Int], която получава списък и число и го добавя към всеки елемент на списъка.

Задача 2. Да се дефинира функция multiplyAllBy :: [Int] -> Int -> [Int], която получава списък и число и умножава всеки елемент на списъка по числото.

Задача 3. Да се дефинира функция filterSmallerThan, която получава списък и число и премахва елементите на списъка, които са по-малки от числото.

Задача 4. Да се дефинира функция isAscending :: Integer -> Bool, която проверява дали цифрите на число са във възходящ ред. Функцията да получава число, но да работи със списък от цифрите му.

Задача 5. Да се дефинира функция digits :: String -> String, която получава низ и намира цифрите в него.

Задача 6. Да се дефинира функция digitsSum :: String -> Int, която намира сумата на цифрите в даден низ.

Задача 7. Да се дефинира функция capitalize :: String -> String, която прави всички малки букви в даден String главни.

Задача 8. Да се дефинира функция isCapitalized :: String -> Bool, която проверява дали всички букви в даден String са главни.
