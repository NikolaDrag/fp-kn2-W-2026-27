# Седмица 2

## 1. Нови функции

### `trace`

Печата всяко влизане (`>`) и всяко излизане (`<`) от функция. Функцията
трябва вече да е дефинирана.

```racket
(require racket/trace)   ; веднъж, горе във файла
(trace fact)             ; след дефиницията на fact
```

`trace` показва процеса. Ето двата `fact` от лекцията.

Рекурсивен процес. Стълбичка: всяко `*` чака резултата отдолу.

```racket
(define (fact n)
  (if (= n 1)
      1
      (* n (fact (- n 1)))))
```

```text
>(fact 4)
> (fact 3)
> >(fact 2)
> > (fact 1)
< < 1
< <2
< 6
<24
```

Итеративен процес. Всичко е на едно ниво, нищо не чака.

```racket
(define (fact n)
  (define (fact-iter product counter)
    (if (> counter n)
        product
        (fact-iter (* product counter) (+ counter 1))))
  (fact-iter 1 1))
```

```text
>(fact-iter 1 1)
>(fact-iter 1 2)
>(fact-iter 2 3)
>(fact-iter 6 4)
>(fact-iter 24 5)
<24
```

### `display`

Печата стойност в REPL. Низът се печата без кавички.

```racket
(display "x = ")   ; печата x =
(display 5)        ; печата 5
(newline)          ; нов ред
(displayln 5)      ; печата 5 и нов ред
```

Това е страничен ефект. Ползваме го само за проверки, не в самите решения.

### `error`

Спира изпълнението със съобщение. Ползваме го при невалиден вход.

```racket
(error "x <= 1")   ; прекъсва програмата и печата x <= 1
```

### Вградени, които ще пишем сами

`gcd` и `abs` са вградени. В задача 1 пишем собствен `gcd`, за да видим как работи.

```racket
(gcd 12 18)   ; → 6
(abs -5)      ; → 5
```

## 2. Видове процеси (лекция 2)

| Процес | Какво става | Пример от лекцията |
|--------|-------------|--------------------|
| линейно рекурсивен | верига от чакащи операции, расте с `n` | `fact` |
| линейно итеративен | нищо не чака. състоянието е в аргументите | `fact` с `fact-iter` |
| дървовидно рекурсивен | всяко обръщение ражда две нови | `fib` |
| итеративен, логаритмичен | броят стъпки расте като `log n` | `gcd` (алгоритъм на Евклид) |

**Опашкова рекурсия.** Рекурсивното обръщение е последното действие във
функцията. След него няма какво да се смята. Racket не трупа стек за такова
обръщение. Затова `trace` на `fact-iter` е на едно ниво.

```racket
(+ a (f (+ a 1)))           ; НЕ е опашково. + чака резултата от f
(helper (+ d 1) count)      ; опашково. резултатът от helper е резултатът
```

Помощната функция (`helper`, `iter`) се дефинира вътре във външната. Вижда
нейните параметри. Лекцията нарича това **блокова структура**. Подробно е в
[седмица 1](../week-01/README.md).

## 3. От лекцията, за по-нататък

`λ` (Ctrl + \\ в DrRacket) ще ползваме от седмица 3–4. Само за ориентация:

```racket
(lambda (x) (* x x))                  ; функция без име
((lambda (x) (* x x)) 4)              ; → 16
(define (sq x) (* x x))               ; същото като
(define sq (lambda (x) (* x x)))      ; ↑

(let ([a 1] [b 2]) (+ a b))           ; → 3. локални имена
(let* ([x 3] [y (+ x 2)]) (* x y))    ; → 15. всяко име вижда предишните
```
