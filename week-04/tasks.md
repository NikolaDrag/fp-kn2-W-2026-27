# Седмица 4 - задачи

Задача 1. Да се дефинира предикат (substr? a b), който проверява дали a е подниз на b, където a и b са естествени числа (например 123 е подниз на 5123783).

Задача 2. Да се дефинира процедура от по-висок ред (derive f eps), която намира първа производна на едноаргументната реална функция f с точност eps.

Задача 3. Да се дефинира процедура от по-висок ред (derive-n f n eps), която намира n-та производна на едноаргументната реална функция f с точност eps.

Задача 4. Ако f и g са числови функции и n е естествено число, да се дефинира функция от по-висок ред (switchsum f g n), която връща като резултат функция, чиято стойност в дадена точка x е равна на f(x)+g(f(x))+f(g(f(x)))+ ... (сумата включва n събираеми).

Примери:

((switchsum (lambda (x) (+ x 1)) (lambda (x) (* x 2)) 1) 2) → 3

((switchsum (lambda (x) (+ x 1)) (lambda (x) (* x 2)) 2) 2) → 9

((switchsum (lambda (x) (+ x 1)) (lambda (x) (* x 2)) 3) 2) → 16

((switchsum (lambda (x) (+ x 1)) (lambda (x) (* x 2)) 4) 2) → 30
