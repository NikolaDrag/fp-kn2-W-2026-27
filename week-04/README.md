# Седмица 4

## 1. Функции от по-висок ред

Функция от по-висок ред е функция, която приема функция като аргумент или връща функция като резултат. В Racket функциите са стойности, също като числата и списъците: можем да ги подаваме, да ги връщаме и да ги пазим с `define`. Представете си го отново като именувани и неименувани "обект функция".

```racket
(map sqr '(1 2 3))   ; → '(1 4 9). map приема функция
((curry + 1) 4)      ; → 5. curry връща функция
```

Когато трябва да върнем функция, препоръчителните начини са два:

- `λ` (или `lambda`) създава функция без име точно там, където ни трябва. В DrRacket `λ` се пише с `Ctrl + \`.
- `curry` взема функция и част от аргументите ѝ и връща функция, която чака останалите.

```racket
(define (add-n n)
  (λ (x) (+ x n)))
((add-n 5) 10)       ; → 15

(define add5 (curry + 5))
(add5 10)            ; → 15
```

## 2. Задача 4 по три начина

`(switchsum f g n)` връща функция, чиято стойност в точка `x` е `f(x) + g(f(x)) + f(g(f(x))) + ...` с `n` събираеми.

Понеже `switchsum` връща функция, се вика с двойни скоби: първото извикване връща функцията, второто я прилага към `x`.

```racket
((switchsum (lambda (x) (+ x 1)) (lambda (x) (* x 2)) 2) 2) ; → 9
```

И в трите варианта `helper` смята сумата. Разликата е само в това как връщаме функцията, която приема `x`.

### Вариант 1: `λ`

```racket
(define (switchsum f g n)
  (define (helper f g i ai sum)
    (define ai+1 (f ai))
    (if (>= i n)
        sum
        (helper g f (+ i 1) ai+1 (+ sum ai+1))))
  (λ (x) (helper f g 0 x 0)))
```

### Вариант 2: `curry`

`curry` попълва аргументите отляво надясно, затова `x` трябва да е последният параметър на `helper`. Тук това е `ai`, който в началото е равен на `x`.

```racket
(define (switchsum f g n)
  (define (helper f g i sum ai)
    (define ai+1 (f ai))
    (if (>= i n)
        sum
        (helper g f (+ i 1) (+ sum ai+1) ai+1)))
  (curry helper f g 0 0))
```

`helper` иска 5 аргумента, а `curry` му дава 4. Затова връща функция, която чака петия.

### Вариант 3: именувана вътрешна функция

Същото като `fx` в `derive` от задача 2.

```racket
(define (switchsum f g n)
  (define (helper f g i ai sum)
    (define ai+1 (f ai))
    (if (>= i n)
        sum
        (helper g f (+ i 1) ai+1 (+ sum ai+1))))
  (define (start x) (helper f g 0 x 0))
  start)
```

На последния ред е `start` без скоби, защото връщаме самата функция, а не резултата от извикването ѝ.

## 3. `map`, `filter`, `foldr` и `foldl`

Това са най-използваните функции от по-висок ред. Всички приемат функция като първи аргумент. Още примери има в [седмица 3](../week-03/README.md).

### `map`

Прилага функцията към всеки елемент и връща списък с резултатите.

```racket
(map (λ (x) (* x x)) '(1 2 3 4))            ; → '(1 4 9 16)
(map (λ (n) (remainder n 10)) '(123 45 6))  ; → '(3 5 6). последната цифра на всяко число
```

### `filter`

Оставя само елементите, за които функцията връща истина.

```racket
(filter even? '(1 2 3 4 5 6))                        ; → '(2 4 6)
(filter (λ (x) (= (remainder x 3) 0)) '(1 3 4 6 9))  ; → '(3 6 9). делящите се на 3
```

### `foldr` и `foldl`

Свиват списъка до една стойност, като започват от начална стойност. Функцията получава два аргумента: първо елемента, после натрупаното досега. `foldr` започва от последния елемент, а `foldl` от първия:

```racket
(foldr f init '(1 2 3))   ; = (f 1 (f 2 (f 3 init))), f е някаква функция на два аргумента
(foldl f init '(1 2 3))   ; = (f 3 (f 2 (f 1 init)))
```

```racket
(foldr + 0 '(1 2 3 4))                                ; → 10
(foldr (λ (x acc) (cons (* 2 x) acc)) '() '(1 2 3))   ; → '(2 4 6). същото като map
```

```racket
(foldl (λ (d acc) (+ (* acc 10) d)) 0 '(1 2 3))   ; → 123. цифрите в число
(foldl cons '() '(1 2 3))                         ; → '(3 2 1). обръща списъка
```
