# Седмица 1 — задачи

Първи ред на файла: `#lang racket`. После Run (F5).

Задачи 1–3 са с `if`, сравнения и аритметика. Няма нужда от рекурсия.
Двата процеса (рекурсивен и итеративен с `helper`) са само в задача 4.

**Задача 1.** Функция `mymin`, два аргумента, връща по-малкия от тях.

```racket
(mymin 3 5)  ; → 3
(mymin 7 1)  ; → 1
```

**Задача 2.** Предикат `inside? x a b` — дали числото `x` е в
затворения интервал `[a, b]`.

```racket
(inside? 3 1 10)   ; → #t
(inside? 0 1 10)   ; → #f
(inside? 10 1 10)  ; → #t
```

**Задача 3.** Функция `myfunc` — средно аритметично на квадратите
на две числа.

```racket
(myfunc 3 4)  ; → 12.5   защото (9 + 16) / 2
```

**Задача 4.** Функция `myfib n` — n-тото число на Фибоначи.

Редица: `1, 1, 2, 3, 5, …`, индексирана от **0**. (F(0) = 1, F(1) = 1,...)

```racket
(myfib 0)  ; → 1
(myfib 1)  ; → 1
(myfib 5)  ; → 8
```

Тук напишете два варианта:

- `myfib` — **рекурсивен** процес
- `myfib-iter` — **линеен итеративен** процес (`helper` с акумулатори)
