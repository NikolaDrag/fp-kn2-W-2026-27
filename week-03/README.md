# Седмица 3

Задачите тази седмица са със средствата от седмица 2. След тях: **списъци**.

---

## 1. Точкови двойки

```racket
(cons 1 2)           ; → '(1 . 2). двойка от два елемента
(car (cons 1 2))     ; → 1. първият
(cdr (cons 1 2))     ; → 2. вторият
(pair? (cons 1 2))   ; → #t
```

`cons` строи двойката. `car` и `cdr` вадят частите ѝ.

---

## 2. Списъци

Списъкът е верига от двойки, която завършва с празния списък `'()`.

```racket
(cons 1 (cons 2 (cons 3 '())))   ; → '(1 2 3)
(list 1 2 3)                     ; → '(1 2 3). същото, по-кратко
'(1 2 3)                         ; → '(1 2 3). цитат
'()                              ; → '(). празен списък
```

Без `'` записът `(1 2 3)` е грешка: Racket опитва да приложи `1` като
функция ([седмица 1](../week-01/README.md)).

`'` (quote) не смята нищо вътре. `list` смята аргументите си.

```racket
'(1 (+ 1 2))       ; → '(1 (+ 1 2))
(list 1 (+ 1 2))   ; → '(1 3)
'a                 ; → 'a. символ: име, не променлива
```

Елементите може да са всякакви, включително други списъци: `'(1 "две" #t (3 4))`.

---

## 3. Достъп до елементи

```racket
(car '(1 2 3))          ; → 1. първият елемент
(cdr '(1 2 3))          ; → '(2 3). всичко без първия
(first '(1 2 3))        ; → 1. като car
(rest '(1 2 3))         ; → '(2 3). като cdr
(second '(1 2 3))       ; → 2. има до tenth
(last '(1 2 3))         ; → 3
(cadr '(1 2 3))         ; → 2. (car (cdr ...))
(caddr '(1 2 3))        ; → 3. (car (cdr (cdr ...)))
(list-ref '(a b c) 1)   ; → 'b. по индекс, от 0
(cdr '(1))              ; → '()
```

`(car '())` и `(first '())` са грешка. Празният списък няма първи елемент.
Преди `car` проверявайте с `null?`.

`first`/`rest` работят само върху списъци. `(car '(1 . 2))` → `1`, а
`(first '(1 . 2))` е грешка.

---

## 4. Проверки

```racket
(null? '())           ; → #t. празен ли е
(empty? '())          ; → #t. същото
(empty? '(1 2))       ; → #f
(pair? '(1 2))        ; → #t. непразният списък е двойка
(pair? '())           ; → #f. празният не е
(list? '(1 2))        ; → #t
(list? '(1 . 2))      ; → #f. двойка, но не списък
(length '(1 2 3))     ; → 3
(length '((1 2) 3))   ; → 2. вложеният списък е един елемент
```

---

## 5. Добавяне

```racket
(cons 0 '(1 2))           ; → '(0 1 2). един елемент отпред
(append '(1 2) '(3 4))    ; → '(1 2 3 4). слепва списъци
(append '(1 2) '(3))      ; → '(1 2 3). отзад: елементът трябва да е в списък
(append '(1) '(2) '(3))   ; → '(1 2 3). произволен брой списъци
```

Капани:

```racket
(cons '(1 2) '(3 4))      ; → '((1 2) 3 4). cons слага ЕДИН елемент, дори да е списък
(cons '(1 2) 3)           ; → '((1 2) . 3). не е списък
(append '(1 2) 3)         ; → '(1 2 . 3). не е списък
```

`cons` отпред е бързо. `append` минава през целия първи списък.

---

## 6. Махане

```racket
(rest '(1 2 3))                    ; → '(2 3). без първия
(take '(0 1 2 3 4) 2)              ; → '(0 1). първите n
(drop '(0 1 2 3 4) 2)              ; → '(2 3 4). без първите n
(drop-right '(0 1 2 3 4) 1)        ; → '(0 1 2 3). без последните n
(remove 2 '(1 2 3 2))              ; → '(1 3 2). само първото срещане
(remove-duplicates '(1 2 1 3 2))   ; → '(1 2 3)
```

При `take`, `drop` и `list-ref` списъкът е първи, числото е второ.
`(take '(1 2) 5)` е грешка.

Списъкът не се променя. Всяка от тези функции връща **нов** списък.

---

## 7. Търсене и равенство

```racket
(member 2 '(1 2 3))            ; → '(2 3). опашката от първото срещане
(member 5 '(1 2 3))            ; → #f
(equal? '(1 2) (list 1 2))     ; → #t. сравнява съдържанието
(eq? (list 1 2) (list 1 2))    ; → #f. два различни обекта в паметта
```

`member` не връща `#t`, а опашката. В `if` и `cond` пак е истина.
Списъци сравняваме с `equal?`. `=` е само за числа: `(= '(1) '(1))` е грешка.

Асоциативен списък е списък от двойки `(ключ . стойност)`:

```racket
(define al '((a . 1) (b . 2)))
(assoc 'b al)         ; → '(b . 2). цялата двойка
(cdr (assoc 'b al))   ; → 2. само стойността
(assoc 'c al)         ; → #f
(caar al)             ; → 'a. ключът на първата двойка
(cdar al)             ; → 1. стойността на първата двойка
```

## 8. Функции върху целия списък

```racket
(map add1 '(1 2 3))             ; → '(2 3 4). функцията върху всеки елемент
(map + '(1 2 3) '(10 20 30))    ; → '(11 22 33). по елемент от всеки списък
(filter odd? '(1 2 3 4 5))      ; → '(1 3 5). оставя тези, за които е #t
(count even? '(1 2 3 4))        ; → 2
(andmap odd? '(1 3 5))          ; → #t. всички ли са
(ormap even? '(1 3 5))          ; → #f. поне един ли е
(apply + '(1 2 3))              ; → 6. като (+ 1 2 3)
(apply max '(4 1 9))            ; → 9
(foldl cons '() '(1 2 3))       ; → '(3 2 1). натрупва отляво
(foldr cons '() '(1 2 3))       ; → '(1 2 3). натрупва отдясно
(reverse '(1 2 3))              ; → '(3 2 1)
(sort '(3 1 2) <)               ; → '(1 2 3)
(range 5)                       ; → '(0 1 2 3 4)
(range 1 6)                     ; → '(1 2 3 4 5). без десния край
```

С `λ` ([седмица 2](../week-02/README.md)) подаваме и своя функция:

```racket
(map (λ (x) (* x 2)) '(1 2 3))         ; → '(2 4 6)
(filter (λ (x) (> x 2)) '(1 2 3 4))    ; → '(3 4)
```

`(map + '(1 2) '(1 2 3))` е грешка. Списъците трябва да са с еднаква дължина.

## 9. Рекурсия по списък

Същата схема като с цифрите от задачите тази седмица:

| Число | Списък |
|-------|--------|
| `(= n 0)`: свършиха ли цифрите | `(null? lst)`: свършиха ли елементите |
| `(remainder n 10)`: последната цифра | `(car lst)`: първият елемент |
| `(quotient n 10)`: без нея | `(cdr lst)`: без него |
| `(+ (* res 10) d)`: строим число | `(cons x lst)`: строим списък |

```racket
(define (sum-list lst)
  (if (null? lst)
      0
      (+ (car lst) (sum-list (cdr lst)))))

(sum-list '(1 2 3))   ; → 6
```
